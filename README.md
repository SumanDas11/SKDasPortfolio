# Suman Kumar Das - Portfolio Website

A professional portfolio website showcasing expertise in test automation, SDET practices, and Playwright testing frameworks. Built with vanilla HTML, CSS, and JavaScript for optimal performance and simplicity.

## 🎯 About

This portfolio highlights 11+ years of experience as a Tech Lead, Principal Consultant, and SDET across 5+ organizations. The site demonstrates expertise in:

- **Test Automation**: Designing scalable automation frameworks and testing solutions
- **Playwright Specialist**: Advanced browser automation and API testing
- **CI/CD Automation**: Quality pipelines and continuous integration strategies
- **API Testing**: Comprehensive API testing and validation
- **Leadership**: Tech Lead and Principal Consultant experience

## 📁 Project Structure

```
├── index.html              # Main portfolio page
├── style.css               # Styling and responsive design
├── script.js               # Interactive functionality
├── README.md               # Project documentation
└── enhancements.txt        # Feature roadmap and improvements
```

## ✨ Features

- **Responsive Design**: Fully responsive across desktop, tablet, and mobile devices
- **Dark Mode**: Toggle between light and dark themes
- **Navigation Sections**:
  - Hero section with compelling headline
  - Professional profile and about section
  - Skills categorized by expertise areas
  - Career experience and timeline
  - Project portfolio
  - Contact information
- **Modern UI**: Professional font pairings (Space Grotesk, DM Sans) with carefully chosen color palette
- **Accessibility**: Semantic HTML, ARIA labels, and keyboard navigation support
- **Interactive Elements**: Dark mode toggle, responsive mobile menu, smooth scrolling

## 🚀 Quick Start

1. Clone or download the repository
2. Open `index.html` in a web browser
3. No build process or dependencies required
